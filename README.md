# scRegPharm: Single-Cell Regulon-Manifold Phenotype Mapping and Tri-Modal Pharmacological Reversal

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)

scRegPharm is a computational framework that unifies single-cell clinical phenotype mapping, 10x Visium spatial transcriptomic niche dissection, and tri-modal pharmacological reversal on a Prior Transcription Factor Regulon Manifold.

---

## 1. Installation

We recommend installing `scRegPharm` inside a clean Python virtual environment (Python >= 3.9):

```bash
git clone https://github.com/zhangdaoyong/scRegPharm.git
cd scRegPharm

python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install -e .
```

## 3. Key Quantitative Benchmark Results

1. **Binomial UMI Capture Downsampling Benchmark on `GSE115978` Counts (`benchmark_dropout_robustness.csv`)**:
   - Across observed single-cell zero fractions from **57.8% (baseline)** up to **97.6% (`p_cap = 0.0003`)**, `scRegPharm` achieves the highest mean **AUROC = 0.9600** (mean AUPRC = 0.9247, within 0.3% of the strongest baseline LP_SGL at 0.9273), ahead of `LP_SGL` (`0.9576`), `DEGAS/Corr` (`0.9494`), `scPAS` (`0.9407`), and `Scissor` (`0.8952`).
   - At conservative FDR cutoffs ($|Z| > 0.75$, FDR $< 0.05$), `scRegPharm` positive calls are near-error-free (mean **precision = 0.991**, recall = 0.229, mean F1 = 0.3324) — a deliberate high-confidence design for feeding the downstream drug-reversal analysis. Threshold-free ranking metrics (AUROC/AUPRC) are the primary comparison; baselines label via unadjusted Z-score cutoffs without FDR control (mean precision 0.925, recall 0.639).
2. **Wall-Clock Runtime & Peak Memory Benchmark on Apple M4 (`benchmark_scalability_m4.csv`)**:
   - Measured via `time.perf_counter()` and `tracemalloc.get_traced_memory()`:
   - At $N = 6,879$ cells (full `GSE115978` atlas): `scRegPharm` runs in **0.126s** and **64.2 MB RAM**, vs. `scPAS` (**0.512s, 659.6 MB**) and a Python/SciPy reimplementation of `Scissor` (**6.087s, 1,117.5 MB** — **48.4x speedup and 17.4x memory reduction**).
   - At $N = 25,000$ cells: `scRegPharm` runs in **0.641s** and **204.4 MB RAM**, vs. `scPAS` (**1.628s, 2,388.1 MB**) and `Scissor` (**61.317s, 8,989.0 MB** — **95.7x speedup and 44.0x memory reduction**).
3. **Single-Cell & Spatial Dissection of Melanoma Immune Exclusion (`melanoma_celltype_enrichment.csv`, `visium_spatial_results.csv`)**:
   - In `GSE115978` ($N = 6,879$ cells), `scRegPharm` maps anti-PD-1 non-response: **74 cells** are classified as `scRegPharm+` (resistant, 1.08%), **719 cells** as `scRegPharm-` (sensitive, 10.45%), and **6,086 cells** as background (88.47%).
   - Resistance enriches in `Malignant_MYC_TCF4_Excl` (**10.26% resistant**, $n = 72/702$), whereas sensitivity enriches in `CD8_T_Cytotoxic_Effector` (**35.82% sensitive**, $n = 663/1,851$) and `cDC1_BATF3_AntigenPres` (**2.17%**, $n = 7/322$).
   - Across $S = 1,461$ 10x Visium spots (`GSE298774`, `GSM9022963_A17`), `scRegPharm-Spatial` partitions the junctional melanocytic lesion into four molecular domains: `Tumor_Core_MYC_SOX10`, `FibroMyeloid_Boundary_SPP1_CAF`, `Peritumoral_Stroma`, and `Excluded_Immune_CD8_MHCII` (Pearson $r = -0.3876, P = 1.41 \times 10^{-53}$, Kruskal-Wallis $H = 616.09, P = 3.27 \times 10^{-133}$).
4. **Tri-Modal Drug Repurposing Benchmark on `A375` LINCS L1000 & DepMap CRISPR (`drug_benchmark_metrics.csv`)**:
   - Tri-modal `scRegPharm-Drug` achieves **AUROC = 0.9713**, **AUPRC = 0.9567**, and **100% Precision@10 (10/10)** across 60 A375 compounds (22 mechanism-annotated benchmark positives: `PLX-4720` #1, `SB590885` #2, `PD-0325901` #3, `CGP-60474` #4, `AZD-8330` #5, `SELUMETINIB` #6, `TRAMETINIB` #7, `FORETINIB` #8, `PD-184352` #9, `MITOXANTRONE` #10).
   - Transcriptome-only variant (excluding CRISPR essentiality) achieves **AUROC = 0.9737**, **AUPRC = 0.9583**, and **100% Precision@10 (10/10)**. Both outperform `DrugReSC` (`AUROC = 0.9581`), `ASGARD` (`AUROC = 0.8086`), and `Bulk-CMap` (`AUROC = 0.2775`).
5. **Multi-Cohort Clinical Validation across $N = 618$ ICB Patients (`clinical_validation_summary.csv`)**:
   - Supervised strictly by binary RECIST non-response, with OS as independent endpoint (uniform $\lambda=5.0, \alpha=0.50, q=0.50$; fixed a priori AUC directions):
   - Statistically significant survival stratification in `PRJEB23709` ($n=73$: Cox $\text{HR} = 1.96$, 95% CI $1.28\text{--}2.99$, Log-rank $P = 1.78 \times 10^{-4}$; $\text{AUROC} = 0.7103$ vs. TIDE $0.5722$), `DFCI_Liu` ($n=122$: Cox $\text{HR} = 1.30$, 95% CI $1.01\text{--}1.68$, Log-rank $P = 0.0144$; $\text{AUROC} = 0.5882$ vs. TIDE $0.5795$), and `IMvigor210` ($n=347$: continuous Cox $\text{HR} = 1.25$ per SD, $P = 0.0010$, median OS 7.1 vs. 10.4 mo; $\text{AUROC} = 0.6205$ vs. TIDE $0.5177$).
   - `GSE91061` ($n=51$: Cox $\text{HR} = 1.30$, Cox $P = 0.134$, Log-rank $P = 0.156$; $\text{AUROC} = 0.5602$).
   - `GSE78220` ($n=25$: Cox $\text{HR} = 0.82$, Log-rank $P = 0.218$), demonstrating statistical power boundaries in small sample sizes ($<30$ patients; 11 OS events, 12 non-responders).
   - Across all 5 cohorts, scRegPharm achieves the highest mean predictive AUROC (mean AUROC = 0.6138 vs. TIDE 0.5759, Bulk-DEG 0.5663, IFN-gamma 0.5945; leading TIDE in 4 of 5 cohorts).

6. **Spatial Permutation Test for the Visium Exclusion Gradient (`visium_spatial_permutation.csv`)**:
   The melanoma Visium exclusion association (Pearson r = -0.388) was re-assessed with a toroidal-translation permutation test (1,000 translations of one module map on the tissue bounding box with nearest-spot reassignment). The observed correlation far exceeded the autocorrelation-preserving null (median |r_null| = 0.095, 95th percentile = 0.232; permutation P = 0.001).

7. **Five-Cohort Fixed-Effect Meta-Analysis (`clinical_meta_analysis.csv`)**:
   Pooled Cox HR = 1.28 per SD (95% CI 1.15–1.43, Z-test P = 4.1 × 10⁻⁶; Cochran Q = 6.09, I² = 34.4%) across all five cohorts; bootstrap 95% CIs for the per-cohort response AUROCs are provided in `clinical_auc_bootstrap_ci.csv`.

## 4. Reproducible Workflow Execution

```bash
# Step 0: Download the 19 raw public archives listed in Section 2 into data/raw_downloads/

# Step 1: Parse and verify raw public datasets + generate SHA256 provenance manifest
python scripts/01_prepare_datasets.py

# Step 2: Run all computational experiments & scalability benchmarks
python scripts/02_run_all_experiments.py

# Step 3: Generate Figures 1–6 (300 DPI PNG + Vector PDF)
python scripts/03_generate_figures_1_to_3.py
python scripts/04_generate_figures_4_to_6.py

# Step 4: Additional benchmarks reported in the manuscript
#   (a) activity-inference comparison against decoupler ULM (Table 4 / Table S9)
#       requires `pip install decoupler` (v2.x)
#   (b) external validation of drug-reversal rankings against GDSC drug-sensitivity
#       panels (Section 3.7 / Table 7 / Table S10). Place these three GDSC
#       release-8.4 archives under data/raw_downloads/ first (rename as shown):
#         GDSC1_fitted_dose_response_24Jul22.csv -> gdsc1_fitted.csv
#         GDSC2_fitted_dose_response_24Jul22.csv -> gdsc2_fitted.csv
#         screened_compounds_rel_8.4.csv         -> compounds_8.4.csv
#       source: https://ftp.sanger.ac.uk/pub/project/cancerrxgene/releases/release-8.4/
python scripts/05_decoupler_headtohead.py
python -m scregpharm.external_drug_validation
```
